# HTML Rules
- Use semantic HTML5 elements (header, main, nav, section, footer) — not just divs everywhere
- Always include `lang="sl"` on the `<html>` tag (Slovenian by default)
- Keep CSS inline or in a `<style>` tag for single-file projects (easier to share and open)
- Make pages mobile-responsive by default: include `<meta name="viewport" content="width=device-width, initial-scale=1">`
- Prefer clean, readable structure — one element per line, indented with 2 spaces
- Never leave placeholder text like "Lorem ipsum" in finished files
