Hooks & Memory

Tihi pomočniki — formatiranje datotek po vsakem urejanju in trajna memorija med sesijami.

🔧 PostToolUse Hook · Prettier auto-format

Po vsakem Write ali Edit tool calu se zažene Prettier in formatira datoteko. Brez ročnega klicanja, brez čakanja. 

"hooks": {
  "postToolUse": [{
    "matcher": "Write|Edit",
    "command": "prettier --write \"$FILE_PATH\""
  }]
}

🧠 Auto-Memory sistem

Trajna memorija preko sesij v ~/.claude/projects/.../memory/. Indeks v MEMORY.md, vsaka memorija lasten .md file s frontmatter (user · feedback · project · reference). Trenutno ~20 vnosov: jezikovne preference, infrastruktura (Hetzner, Dokploy), trenutni klienti, projektne odločitve.

Konfiguracija

Kje živi setup

Strukturirani .md fajli s CLAUDE.md hierarhijo — global, agencija, projekt, pravilo.

~/.claude/CLAUDE.md

Globalna pravila

Tech environment, OS, jezikovni privzetki, gotcha-ji (Windows paths, OneDrive sync, API rate limits).

~/.claude/settings.json

Model + Hooks + MCP

Model: claude-opus-4-7. Prettier hook, Dokploy MCP server, GitHub PAT.

~/OneDrive/Desktop/context.md

O meni

Kdo sem, kako naj me Claude uči, kako naj ureja prozo, splošni delovni stil.

~/OneDrive/Desktop/acenta/CLAUDE.md

Agencijska pravila

O Acenti, vsesplošna pravila za kliente, jeziki, format outputa, prepovedi.

acenta/projects/*/CLAUDE.md

Projektna pravila

Per-projekt: LeadScanner (pipeline, module pattern), Hotel Analyzer (tech stack), Ponudbe.

projekt/.claude/rules/*.md

Granularna pravila

Module pattern, Airtable fields, scoring, API safety, env vars — referencirana iz CLAUDE.md.

~/.claude/agents/*.md

Custom agenti

6 lastnih agentov: design-turizem-sl, copywriting-storytelling, client-brief-analyzer, in več.

~/.claude/skills/*/SKILL.md

Skill paketi

Vsak skill v lastni mapi s SKILL.md + assets. Najdaljši: devtakeover, ads, design.

.../memory/MEMORY.md

Auto-memorija

Indeks + ~20 individualnih memory fajlov: jezikovne preference, infra IP-ji, klienti, projekti.
